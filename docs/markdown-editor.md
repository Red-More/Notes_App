# Markdown 编辑器与预览：实现说明与使用文档

## 1. 概述

笔记编辑页已从 `textarea` 升级为 **CodeMirror 6** 编辑器，并把预览升级为 **markdown-it** 渲染器（VS Code 内置 Markdown 预览同款引擎）。预览以可调节高度的上下分屏呈现，支持内容实时同步、双向滚动同步、点击预览定位源码行、分隔线拖拽/点击调整区域比例，以及 Mermaid 图表与 KaTeX 数学公式渲染。

核心目标：

- 移动端获得接近 VS Code 的 Markdown 编辑体验；
- 预览渲染使用成熟引擎，不自行实现 Markdown 解析；
- 保留既有的编辑态、输入法联动、取消/确认与保存策略。

## 2. 技术选型

| 层            | 方案                                                      | 说明                                               |
| ------------- | --------------------------------------------------------- | -------------------------------------------------- |
| 编辑器        | CodeMirror 6                                              | 行号、折行、选区、撤销栈、语法树、移动端输入均内置 |
| Markdown 语言 | `@codemirror/lang-markdown` + `@codemirror/language-data` | Markdown 高亮；围栏代码按需加载语言高亮            |
| 缩进参考线    | `@replit/codemirror-indentation-markers`                  | 成熟社区扩展                                       |
| 预览渲染      | `markdown-it`                                             | CommonMark + GFM 表格/删除线/自动链接              |
| 任务列表      | `markdown-it-task-lists`                                  | GFM 待办列表                                       |
| Mermaid       | `mermaid`（懒加载）                                       | 流程图、时序图、类图、状态图、甘特图等全部图表类型 |
| 数学公式      | `katex` + `@vscode/markdown-it-katex`                     | 行内 `$...$` 与块级 `$$...$$`，VS Code 同款方案    |
| 代码高亮      | `highlight.js/lib/common`                                 | 预览内常见语言高亮                                 |
| 高亮配色      | 自定义 CSS（基于应用设计变量）                            | 浅色/深色主题自动适配                              |

## 3. 编辑器能力

### 3.1 行号与滚动

- 行号 gutter 由 CodeMirror 渲染，与内容共用同一个滚动容器，天然同步滚动。
- 行号使用等宽数字，活动行号以强调色显示。

### 3.2 智能视觉折行

- 启用 `EditorView.lineWrapping`：仅做视觉折行，不插入真实换行符，不改变 Markdown 语义与源码行号。
- 行号按逻辑行编号，长行折行后不会被拆成多行。

### 3.3 缩进

- 自动缩进：`indentOnInput()` + Markdown 语言缩进规则。
- Tab / 空格缩进：设置页可配置，持久化到 `localStorage`（`notes:editor-prefs`）。
- 缩进宽度支持 2 / 4 / 8；Tab 模式下按 Tab 插入制表符，显示宽度由 `EditorState.tabSize` 控制。
- 缩进层级可视化：缩进参考线，活动缩进块以强调色加粗。
- 硬件键盘下的 `Tab / Shift-Tab` 支持增加/减少缩进。

### 3.4 视觉

- 主题全部使用应用 CSS 变量（`--text`、`--surface-2`、`--accent` 等），浅色/深色主题自动切换。
- 活动行背景高亮、行号强调、光标 2px 强调色、选区半透明强调色。
- 行内代码、标题、链接、引用、列表标记、Markdown 标点均有独立配色。
- 正文使用等宽字体栈，行高 1.75；预览使用阅读字体。

### 3.5 Markdown 语法高亮与实时提示

- 基于 Lezer Markdown 语法树实时高亮，无需等待解析完成。
- 实时语法提示：
  - 行首输入 `#`、`-`、`*`、`+`、`>` 时弹出对应 Markdown 结构建议；
  - 硬件键盘可用 `Ctrl+Space` 主动唤起全部片段（代码块、表格、加粗、链接等）；
  - 未闭合的围栏代码块会以波浪线提示“代码块未闭合”；
  - 括号匹配、选中内容同词高亮由 CodeMirror 提供。

### 3.6 快捷键

| 快捷键                  | 功能                           |
| ----------------------- | ------------------------------ |
| `Mod+B`                 | 加粗（再次按下取消）           |
| `Mod+I`                 | 斜体                           |
| `Mod+E`                 | 行内代码                       |
| `Mod+K`                 | 插入链接，并选中 `url` 占位符  |
| `Tab` / `Shift+Tab`     | 增加 / 减少缩进                |
| `Enter`                 | 在列表/引用内自动续行          |
| `Backspace`             | 行首删除列表/引用标记          |
| `Mod+Z` / `Mod+Shift+Z` | 撤销 / 恢复（CodeMirror 历史） |
| `Ctrl+Space`            | Markdown 片段补全              |
| `Ctrl/Cmd+S`            | 立即保存（应用级快捷键）       |

移动端软键盘没有组合键，以上快捷键主要面向外接键盘。

## 4. 预览能力

### 4.1 支持的语法

- CommonMark：标题、段落、强调、列表、引用、代码、分隔线、链接、图片。
- GFM 扩展：表格、删除线、自动链接、任务列表（只读复选框）。
- 围栏代码块：按 info string 使用 highlight.js 常见语言高亮；未知语言按纯文本显示。
- Mermaid：以 ` ```mermaid ` 围栏标记，支持 Mermaid 官方解析器覆盖的全部图表类型（流程图、时序图、类图、状态图、甘特图、ER 图、饼图等）。
- LaTeX：行内 `$...$`、块级 `$$...$$`，由 KaTeX 渲染；也支持 `$$\begin{aligned}...\end{aligned}$$` 等复杂结构。
- 软换行遵循 CommonMark：源码中的单个换行在预览中显示为空格，与 VS Code 默认行为一致。

### 4.2 明确不支持

- 原生 HTML：`html: false`，HTML 标签会被转义为文本。

### 4.3 安全

- Markdown 原始 HTML 关闭，避免脚本注入。
- 链接协议由 markdown-it 校验，`javascript:` 等危险协议不会生成可点击链接。
- 预览中的外链点击不会让 WebView 跳离应用，而是复制链接并提示在浏览器打开。
- KaTeX 使用 `trust: false`，不执行 `\href`、`\htmlClass` 等可信命令。
- Mermaid 使用 `securityLevel: 'strict'` 与 `suppressErrorRendering`，标签会被安全处理，错误不会注入页面。

### 4.4 源码行映射

渲染时给块级元素注入 `data-line`（1-based 源码行号），用于：

- 编辑器滚动 → 预览定位；
- 预览滚动 → 编辑器定位；
- 点击预览段落 → 编辑器选中对应源码行（不会唤起键盘）。

表格内部行/单元格不参与映射，避免 `offsetParent` 不同导致行号错乱。

### 4.5 Mermaid 与 LaTeX 渲染

**自动识别**

- 围栏语言为 `mermaid`（大小写不敏感）时自动识别为图表，无需切换渲染模式；
- `$...$` 自动作为行内公式，`$$...$$` 自动作为块级公式；
- 代码围栏、行内代码中的 `$` 不会被误判；金额（如 `$20,000`）不会触发公式解析。

**Mermaid 渲染流程**

- markdown-it 先输出带 `data-line` 的 `.mermaid-block` 占位符与源码；
- 预览挂载后由浏览器调用 Mermaid 渲染 SVG；引擎通过动态 `import('mermaid')` 懒加载，无图表笔记不下载；
- 渲染结果按「主题 + 源码」缓存（最多 40 条），内容未变的图表在后续刷新中直接复用；
- 同一时间只顺序渲染一个图表，避免 Mermaid 全局解析状态冲突；
- 语法错误显示「图表渲染失败」、错误详情与原始源码，不抛出异常、不破坏页面；
- 超宽图表在容器内自适应缩放，容器保留横向滚动兜底。

**KaTeX 渲染流程**

- `@vscode/markdown-it-katex` 负责解析 `$` / `$$`，KaTeX 负责排版；
- 块级公式外层为 `.math-block` 并带 `data-line`，支持滚动同步与点击定位；
- 行内公式在段落内正常换行；块级公式超宽时在容器内横向滚动；
- 公式错误显示「公式语法错误」；块级错误额外展示源码与解析详情；
- 引入 `katex/dist/katex.min.css` 与字体资源，字体按实际用到的字符懒加载。

**主题与样式**

- 浅色使用 Mermaid `default` 主题，深色使用 `dark` 主题；主题取自应用当前 `data-theme`；
- KaTeX 颜色沿用 Markdown 前景色，错误使用应用的危险色；
- 所有图表/公式样式限定在 `.md-preview` 内，不影响编辑器与其他页面。

## 5. 双向同步

### 5.1 内容同步

- 编辑器每次文档变更立即更新 `content` 状态；
- 预览通过 `useDeferredValue` 延迟渲染，避免连续输入阻塞输入法；
- 预览 HTML 通过 `useMemo` 缓存，仅在内容变化时重新渲染；
- 预览模块（markdown-it / KaTeX / highlight.js）按需加载，仅在打开预览时下载；Mermaid 引擎进一步延迟到存在图表时才加载。

### 5.2 滚动同步

- 编辑器滚动：取视口顶部行号 → 预览滚动到对应块；
- 预览滚动：取视口顶部块的行号 → 编辑器滚动到对应行；
- 两个方向都设置 160ms 的“程序化滚动抑制窗口”，避免相互触发形成抖动；
- 编辑器滚动监听挂在 CodeMirror 的 `.cm-scroller` 上（滚动事件不冒泡）；
- 预览块位置在每次 HTML 变化后以及容器尺寸变化时重新测量（`ResizeObserver`）。

### 5.3 布局模式与比例

- 三种模式：**仅编辑**（预览关闭）、**分屏**、**仅预览**（隐藏编辑区）；
- 分屏比例可调范围为 **10%-90%**，默认 55%（编辑区）/ 45%（预览区）；
- 分隔线为 2px 高对比线（次级文本色），中央带 52×8px 手柄；24px 高整行热区保持不变，悬停时线宽增至 3px、手柄变宽并使用强调色，拖拽时进一步强化反馈；
- 拖拽过程中逐帧更新区域尺寸，松开后写入本地配置；点击分隔线快速翻转主区域（接近 50/50 时切换到 70/30）；聚焦分隔线后可用上下方向键微调；
- 布局配置保存在 `notes:editor-layout`（`ratio` / `previewOpen` / `previewOnly`），刷新页面后自动恢复；
- 软键盘弹出时，页面按键盘 inset 增加底部内边距，两个面板同步收缩。

## 6. 移动端与输入法

- 点击标题或正文（含编辑器空白区域）→ 聚焦编辑器/标题、唤起系统输入法、显示编辑操作栏；
- 编辑操作栏：左侧取消，右侧撤销 / 恢复 / 确认，按钮均为 44×44px 热区；
- 操作按钮在 `pointerdown` 时阻止默认行为，避免抢走焦点导致输入法收起；
- 主动收起输入法（键盘返回键 / 收起按钮）→ 自动失焦退出编辑态、隐藏操作栏；
- 键盘弹出时编辑器会调用 `scrollIntoView` 保证光标可见；
- Android 采用原生 IME inset 桥接（`notes-keyboard-inset`），iOS/其他 WebView 采用 `visualViewport`。

## 7. 设置

设置页新增「Markdown 编辑器」与「预览布局」两个区域：

**Markdown 编辑器**

- 缩进方式：空格 / Tab
- 缩进宽度：2 / 4 / 8
- 配置持久化到 `notes:editor-prefs`，重新打开笔记编辑页后生效。

**预览布局**

- 布局模式：仅编辑 / 分屏 / 仅预览
- 编辑区 / 预览区比例：10%-90% 滑块，并实时刷新下方的布局缩略图
- 「恢复默认设置」：清除 `notes:editor-layout`，恢复默认比例 55/45、仅编辑模式，并弹出成功提示
- 布局配置在调整时即时保存；在笔记页拖拽分隔线也会同步更新该比例
- 「仅预览」模式下编辑区与分隔线隐藏，仅显示笔记标题与渲染结果

预览开关位于笔记页顶部眼睛图标；编辑态下操作栏会占用顶栏，退出编辑后可切换预览。

## 8. 性能与加载

- 主界面不包含 CodeMirror / markdown-it / KaTeX / highlight.js / Mermaid；
- 当前构建：主包约 307KB（gzip 93KB），编辑器分包约 136KB（gzip 44KB）；
- 预览分包约 792KB（gzip 254KB），另含 KaTeX 分包约 259KB（gzip 78KB），仅在打开预览时加载；
- Mermaid 引擎在存在图表时才下载，各图表类型独立分包（常规流程图/时序图分包远小于最大的复杂图表分包）；
- 围栏代码语言的语法包按需动态加载，不进入首屏；
- 预览渲染使用 React 延迟值，输入法输入不被渲染阻塞；
- 滚动同步按“行变化”触发，不处理每个滚动像素；预览重测量仅在内容或尺寸变化时执行；
- 分隔线拖拽使用 `requestAnimationFrame` 合并更新，避免高频布局计算导致卡顿；
- Mermaid 渲染结果按主题与源码缓存，重复刷新不重复渲染；KaTeX 字体按需加载。

## 11. 已知限制

- 单换行不渲染为 `<br>`，与 VS Code / CommonMark 默认一致；需要换行请使用空行。
- 原生 HTML 仍不解析（按需求关闭）。
- Mermaid / KaTeX 首次使用需要加载额外资源；Mermaid 首次渲染是异步的，复杂图表在窄屏按容器宽度缩放。
- Mermaid 语法覆盖范围由 Mermaid 官方解析器决定；KaTeX 不支持的命令会显示降级提示。
- 未启用脚注等非 GFM 扩展。
- 外链通过剪贴板复制，不直接唤起系统浏览器（当前未引入 opener 插件）。
- 缩进配置在重新打开笔记后生效。
- 布局比例限制在 10%-90%，仅预览模式通过设置页切换；配置保存在本机 `localStorage`，不跨设备同步。
- 设置页的布局修改在下次打开笔记时生效（设置页与编辑页不同时显示），分隔线拖拽则在当前页面即时生效。
