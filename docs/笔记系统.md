
## 二、笔记系统

### 2.1 笔记列表模块

#### 2.1.1 模块概述

笔记列表是应用的首页，展示用户所有笔记，支持文件夹筛选、搜索、批量操作等功能。

#### 2.1.2 核心功能

| 功能         | 描述                             | 实现状态 |
| ------------ | -------------------------------- | -------- |
| 笔记列表展示 | 按更新时间倒序展示，置顶笔记优先 | 🚧 待实现       |
| 文件夹筛选   | 顶部横向Tab切换不同文件夹        | 🚧 待实现       |
| 搜索功能     | 支持标题和内容模糊搜索           | 🚧 待实现       |
| 下拉刷新     | 下拉刷新笔记列表                 | 🚧 待实现       |
| 新建笔记     | 点击FAB按钮创建新笔记            | 🚧 待实现       |
| 批量选择     | 长按进入选择模式                 | 🚧 待实现       |
| 置顶功能     | 将笔记固定在列表顶部             | 🚧 待实现       |
| 移动到文件夹 | 批量移动笔记到指定文件夹         | 🚧 待实现       |
| 批量删除     | 批量删除选中的笔记               | 🚧 待实现       |

#### 2.1.3 用户操作流程

**流程1：查看笔记**

```
1. 用户进入应用 → 自动加载笔记列表
2. 笔记按更新时间倒序排列，置顶笔记显示📌图标
3. 用户点击笔记卡片 → 跳转到笔记编辑页面
```

**流程2：文件夹筛选**

```
1. 用户在顶部文件夹Tab区域左右滑动
2. 点击"全部"标签 → 显示所有笔记
3. 点击具体文件夹标签 → 只显示该文件夹下的笔记
4. Tab切换时，列表自动刷新
```

**流程3：搜索笔记**

```
1. 用户点击搜索框 → 键盘弹出
2. 输入搜索关键词 → 实时搜索标题和内容
3. 按下回车键 → 执行搜索，显示匹配结果
4. 清空搜索框 → 显示当前文件夹下所有笔记
```

**流程4：批量操作**

```
1. 用户长按某个笔记卡片 → 进入选择模式
   - 顶部显示"已选择X项"提示
   - 底部显示操作栏：设为导出、置顶、移动到、删除
   - 被选中的笔记卡片显示蓝色选中框
2. 用户点击其他笔记 → 添加到选中集合
3. 用户点击"全选"按钮 → 选中当前列表所有笔记
4. 用户点击"取消"按钮 → 退出选择模式
```

**流程5：置顶笔记**

```
1. 用户在选择模式下选中笔记
2. 点击"置顶"按钮
3. 列表刷新，置顶笔记显示在顶部并带有📌图标
```

**流程6：移动笔记**

```
1. 用户在选择模式下选中笔记
2. 点击"移动到"按钮 → 弹出文件夹选择
3. 显示所有文件夹列表（包括"默认"）
4. 用户点击目标文件夹
   - 笔记所在的文件夹更新
   - 列表刷新
   - 退出选择模式
```

**流程7：删除笔记**

```
1. 用户在选择模式下选中笔记
2. 点击"删除"按钮
3. 删除成功 → 列表刷新，退出选择模式
```

### 2.2 笔记编辑模块

#### 2.2.1 模块概述

笔记编辑页面是应用的核心功能，支持实时编辑、自动保存、版本控制、标签管理等高级功能。

#### 2.2.2 核心功能

| 功能         | 描述                       | 实现状态 |
| ------------ | -------------------------- | -------- |
| 实时编辑     | 支持标题和内容实时编辑     | 🚧 待实现       |
| 自动保存     | 内容变化1秒后自动保存      | 🚧 待实现       |
| 手动保存     | 返回时强制保存             | 🚧 待实现       |
| 文件夹选择   | 选择笔记所属文件夹         | 🚧 待实现       |
| 版本查看     | 查看历史版本列表           | 🚧 待实现       |
| 版本预览     | 预览历史版本内容           | 🚧 待实现       |
| 版本对比     | 对比当前版本与历史版本差异 | 🚧 待实现       |
| 版本恢复     | 恢复到指定历史版本         | 🚧 待实现       |

#### 2.2.3 用户操作流程

**流程1：新建笔记**

```
1. 用户在笔记列表点击右下角"+"按钮
2. 跳转到编辑页面，自动带上folderId参数（如果在某个文件夹下）
3. 用户开始输入标题和内容
4. 输入后1秒自动保存，创建笔记记录
5. 同时创建第一个版本
```

**流程2：编辑现有笔记**

```
1. 用户在笔记列表点击笔记卡片
2. 跳转到编辑页面，加载笔记数据
3. 用户修改标题或内容
4. 内容变化1秒后自动保存
5. 如果距离上次版本创建超过30秒，自动创建新版本
6. 用户点击返回按钮 → 强制保存并创建版本
```

**流程3：选择文件夹**

```
1. 用户点击"文件夹"选择器
2. 弹出文件夹选择Modal
3. Modal显示所有文件夹列表
4. 用户点击目标文件夹 → 更新笔记所属文件夹
5. Modal关闭，界面显示新的文件夹名称
```

**流程4：查看历史版本**

```
1. 用户点击顶部时钟图标 → 打开历史版本Modal
2. Modal加载版本列表，按版本号倒序排列
3. 每个版本显示：
   - 版本号（v1.0.0格式）
   - 标题
   - 创建时间
   - 标签（如果有）
4. 用户点击版本项 → 进入版本预览模式
```

**流程5：版本预览模式**

```
1. 用户点击某个版本 → 进入版本预览
2. 界面切换为只读模式：
   - 顶部显示"历史版本预览"提示
   - 标题和内容不可编辑
   - 显示该版本的内容
3. 用户可以：
   - 点击"载入编辑"按钮 → 加载到编辑区
   - 点击返回按钮 → 退出预览
```

**流程6：载入历史版本到编辑区**

```
1. 用户在版本预览模式下点击"载入编辑"按钮
2. 如果当前有未保存的更改：
   - 弹出警告对话框："当前存在未保存的更改，加载历史版本将覆盖这些内容"
   - 用户选择"取消"或"继续加载"
3. 执行加载：
   - 备份当前标题和内容
   - 将历史版本内容填充到编辑区
   - 退出预览模式
   - 显示"撤销"横幅（5秒后自动消失）
4. 用户可以点击"撤销"按钮 → 恢复之前的内容
```

**流程7：恢复历史版本**

```
1. 用户在版本列表中点击恢复图标（旋转箭头）
2. 弹出确认对话框："确定要恢复到 vX.X.X 吗？"
3. 用户确认 → 调用恢复API
4. 后台操作：
   - 将笔记内容更新为该版本内容
   - 创建新的"恢复自 vX.X.X"标签版本
5. 界面刷新，显示恢复的内容
```

**流程8：版本对比**

```
1. 用户在版本列表中点击对比图标（代码对比）
2. 弹出版本对比Modal
3. 显示对比结果：
   - 统计栏：+X行新增，-X行删除
   - 内容区：绿色标记新增行，红色标记删除行
   - 每行显示行号和内容
```

**流程9：创建标签**

```
1. 用户点击顶部书签图标 → 弹出标签菜单
2. 点击"新建标签" → 打开创建标签Modal
3. 输入标签名称（必填）和描述（可选）
4. 点击"创建标签"按钮
5. 后台操作：
   - 创建当前内容的版本
   - 设置标签名称和描述
   - 标记为is_manual=true
6. 创建成功 → 显示成功提示
```

**流程10：管理标签**

```
1. 用户点击顶部书签图标 → 弹出标签菜单
2. 点击"标签列表" → 打开标签列表Modal
3. 显示所有带标签的版本
4. 用户点击标签项 → 预览该版本
5. 用户长按标签项 → 弹出操作菜单：
   - 编辑标签：修改标签名称和描述
   - 删除标签：移除标签（版本内容保留）
   - 恢复到此版本
```

### 2.4 版本管理系统

#### 2.4.1 模块概述

版本管理系统是笔记系统的核心高级功能，支持完整的内容历史追溯、版本对比和恢复操作。

#### 2.4.2 版本控制策略

**版本号格式**

```
v{major}.{minor}.{patch}
例如：v1.2.3

计算公式：
major = version_number / 100
minor = (version_number % 100) / 10
patch = version_number % 10
```

**版本创建时机**

| 场景                       | 是否创建版本  | 说明             |
| -------------------------- | ------------- | ---------------- |
| 新建笔记                   | 🚧 待实现 强制创建   | 创建第一个版本   |
| 内容变化 + 距上次版本≥30秒 | 🚧 待实现 自动创建   | 自动保存触发     |
| 手动返回/保存              | 🚧 待实现 强制创建   | 用户主动保存     |
| 创建标签                   | 🚧 待实现 强制创建   | 用户标记重要版本 |
| 内容无变化                 | ❌ 跳过       | 避免冗余版本     |
| 版本恢复                   | 🚧 待实现 创建新版本 | 记录恢复操作     |

**版本清理策略**

```typescript
const MAX_VERSIONS = 20; // 最多保留20个版本

// 智能清理规则：
// 1. 始终保留最新版本
// 2. 保留所有带标签的版本（label不为null）
// 3. 删除最旧的、无标签的、自动创建的版本
```

#### 2.4.3 版本操作矩阵

| 操作     | 描述                       | 影响范围                     |
| -------- | -------------------------- | ---------------------------- |
| 查看版本 | 预览历史版本内容           | 只读，无影响                 |
| 载入编辑 | 将历史版本内容加载到编辑区 | 修改编辑区内容，不创建新版本 |
| 恢复版本 | 将笔记恢复到指定版本       | 创建新版本，更新笔记内容     |
| 版本对比 | 对比两个版本的差异         | 只读，无影响                 |
| 创建标签 | 为当前内容创建标记版本     | 创建新版本                   |
| 编辑标签 | 修改版本标签信息           | 不创建新版本，只更新标签     |

### 2.5 标签管理系统

#### 2.5.1 模块概述

标签管理系统允许用户为笔记的重要状态创建标记版本，方便后续快速定位和恢复。

#### 2.5.2 核心功能

| 功能     | 描述                       | 实现状态 |
| -------- | -------------------------- | -------- |
| 创建标签 | 为当前内容创建带标签的版本 | 🚧 待实现       |
| 标签列表 | 查看所有标签版本           | 🚧 待实现       |
| 编辑标签 | 修改标签名称和描述         | 🚧 待实现       |
| 删除标签 | 移除标签（版本内容保留）   | 🚧 待实现       |
| 标签保护 | 标签版本不会被自动清理     | 🚧 待实现       |

#### 2.5.3 用户操作流程

**流程1：创建标签**

```
1. 用户在编辑页面点击书签图标
2. 弹出标签菜单，选择"新建标签"
3. 打开创建标签Modal
4. 输入：
   - 标签名称（必填，最多50字符）
   - 标签描述（可选）
5. 点击"创建标签"按钮
6. 后台操作：
   - 创建当前内容的版本
   - 设置标签信息
   - 标记is_manual=true
7. 成功提示
```

**流程2：查看标签列表**

```
1. 用户在编辑页面点击书签图标
2. 弹出标签菜单，选择"标签列表"
3. 显示所有标签版本
4. 每个标签显示：
   - 版本号
   - 标签名称
   - 标签描述
   - 创建时间
```

**流程3：编辑标签**

```
1. 用户在标签列表中长按标签项
2. 弹出操作菜单：编辑标签、删除标签、恢复到此版本
3. 选择"编辑标签"
4. 打开编辑Modal，显示当前标签信息
5. 修改后点击"保存"
6. 后台更新标签信息（不创建新版本）
```

**流程4：删除标签**

```
1. 用户在标签列表中长按标签项
2. 选择"删除标签"
3. 弹出确认对话框
4. 确认后：
   - 清空label和label_description字段
   - 版本内容保留
   - is_manual保持true
```

#### 2.5.4 标签保护机制

**保护规则**

- 🚧 待实现 有标签的版本（label不为null）：永不被自动清理
- 🚧 待实现 最新版本：永不删除
- ❌ 自动创建且无标签的旧版本：可能被清理
