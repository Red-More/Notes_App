Notes · 图标候选 v1 / v2 对比

每个方案给出 v1（上一轮基准）与 v2（本轮修正）的原生渲染：16 / 24 / 32 / 48 / 256 / 1024 px。所有 PNG 均由 SVG 按目标尺寸直接渲染，没有先放大再缩小。透明背景，未改动 src-tauri/icons/ 与 tauri.conf.json。

这一轮修的是什么：A 增加小尺寸可保留的装订边；B 改为浅桃底板以适配浅色 UI；C 放大并锐化星芒、去掉文本条，使 24–32px 仍能读出星形。每个方案下方列出具体数值改动与对比度依据。
A
