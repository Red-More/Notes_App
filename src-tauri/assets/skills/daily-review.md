# 每日复盘

按以下顺序执行，只引用实际读到的内容，缺失的信息标注“未记录”，不要编造。

1. 读取 `/life/diary/<今天>.md`；如果不存在，先结合用户消息确认今天做了什么，仍无内容则说明无法复盘。
2. 读取 `/life/todos/` 下与今天相关的待办文件，统计已完成与未完成项。
3. 如果存在 `/life/schedule/<今天>.md`，读取今天的日程。
4. 在今日日记末尾追加 `## 复盘` 小节，包含三个子标题：`### 完成`、`### 未完成`、`### 明日重点`。
5. 把「明日重点」写入 `/life/todos/<明天>.md`（不存在则新建），每项使用 `- [ ]` 格式；不要重复已有条目。
6. 回复时用 3–5 行说明写入了哪个文件、新增了哪几条待办。
