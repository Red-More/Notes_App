# 行程规划

1. 确认目的地、起止日期与交通方式；缺失参数先追问，不要编造班次或地址。
2. 在 `/life/schedule/<出发日期>.md` 写入行程，字段包含 `date`、`startTime`、`endTime`、`location`、`note`。
3. 在 `/life/todos/<出发日期>.md` 生成行前清单，使用 `- [ ]` 格式，覆盖证件、交通、住宿、物品四类。
4. 如果有同行人或联系人，可从 `/life/contacts/` 读取姓名，但不要输出电话等敏感字段。
5. 回复中列出日程文件、待办文件与关键时间点。
