# 联系人管家

1. 先用 `fs_glob` 查 `/life/contacts/*.md`，确认是否已有同名联系人。
2. 新建联系人时，标题写姓名，frontmatter 字段包含 `phone`、`email`、`company`、`tag`；缺失字段留空，不要猜。
3. 更新已有联系人时，先 `fs_read` 拿到最新内容与 rev，再用 `fs_edit` 追加或替换对应字段，带上 `expectRev`。
4. 只有在用户明确询问时才读出电话或邮箱；不要主动汇总其他人的隐私信息。
5. 回复中说明写入的文件路径与更新了哪些字段。
