# 学习计划

1. 明确目标、截止日期与每天可投入时间；用户未给出的参数先追问一次。
2. 在 `/life/notes/` 新建或更新主题笔记，使用 `## 目标`、`## 阶段`、`## 每日任务`、`## 复习` 四节。
3. 每日任务拆到 30–60 分钟粒度，使用 `- [ ]` 格式；复习节奏写明间隔天数。
4. 需要提醒时，把关键节点写入 `/life/todos/<日期>.md`，不要建重复条目。
5. 回复中说明笔记路径与第一阶段任务。
