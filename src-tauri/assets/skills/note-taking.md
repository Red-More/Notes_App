# 笔记整理

1. 判断内容主题，用简短标题命名，路径优先复用 `/life/notes/` 下已有同名笔记。
2. 新建笔记时使用 `# 标题` 开头，按内容自动分段，必要时加 `## 小节`；frontmatter 的 `tags` 写 1–3 个关键词。
3. 追加内容前先 `fs_read` 文件尾部，再用 `fs_edit` 以末尾片段为锚点追加，带上 `expectRev`。
4. 保留用户原话中的关键数据，不要扩写或编造事实。
5. 回复中给出笔记路径与一句话摘要。
