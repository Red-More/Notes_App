# 周复盘

1. 用 `fs_glob` 找出本周（周一至周日）的日记文件，逐个读取；只统计实际存在的内容。
2. 读取 `/life/todos/` 下本周相关文件，统计完成与未完成项。
3. 在 `/life/notes/` 新建 `周复盘-<本周一日期>.md`，包含 `## 本周完成`、`## 未完成与原因`、`## 下周重点` 三节。
4. 把「下周重点」写入 `/life/todos/<下周一日期>.md`，使用 `- [ ]` 格式。
5. 回复中说明覆盖了哪几天、创建了哪个文件；不要虚构未记录的事件。
