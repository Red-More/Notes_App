## 3. 变更清单（按文件）

### 3.1 `src/editor/commands.ts` — 纯函数化行前缀命令

新增两个可单测的纯函数，返回 `{ changes, range }`：

```ts
export function toggleLinePrefixRange(
  state: EditorState,
  range: SelectionRange,
  prefix: string,
): RangeEdit

export function cycleHeadingRange(
  state: EditorState,
  range: SelectionRange,
): RangeEdit
```

**`toggleLinePrefixRange` 规则**

- 选中行仍沿用当前边界逻辑：选区结束在下一行行首时不计入该行（现有实现保留）。
- 全部行已以 `prefix` 开头 → 批量删除；否则只给**缺少前缀**的行插入，避免混合选区产生 `- - ` 重复。
- 光标：
  - 单行折叠：插入 → 原光标 + `prefix.length`；取消 → 该行行首。
  - 多行选区：统一落到**最后一行正文末尾**（按该行是否被增删前缀换算）。
- 返回 `EditorSelection.cursor(...)`，不再依赖默认映射。

**`cycleHeadingRange` 规则**

- 用 `/^#{1,6} /` 识别现有 ATX 标题；以第一行级别为基准：无标题 → H1，H1–H5 → 下一级，H6 → 清空。
- 所有选中行统一替换为同一目标级别。
- 光标：单行 → 行首 + 新前缀长度（保证落在 `#… ` 右侧）；取消 → 行首；多行 → 最后一行正文末尾。

## 5. 假设与决策

1. **设置 Tab 仍是 sticky（不是 fixed）**：保留 `position: sticky`，但去掉负 margin 与左右 padding，让它作为滚动内容的第一行参与布局；头部与 Tab、Tab 与分组之间统一用 8px token，不再有悬空 margin。
2. **横向联动语义**：设置内容本身是纵向长页，因此「导航横向滚动 ↔ 内容分类」实现为：
   - 内容纵向滚动 → active chip 更新，并自动横向居中；
   - 用户横向滑动导航并停稳 160ms → 最近中心 chip 对应的分组平滑跳转；
   - 点击 chip → 分组跳转。
   程序化滚动用时间戳守卫，避免自激。这是对 Issue 描述的可落地解释。
3. **标题循环基准**：多行混合级别时以第一行级别为基准统一替换，保证连续点击行为可预测。
4. **尾区高度**：初始 `18vh`，真机可调；不写死 px、不加 DOM 行号。
5. **新增 `ordered` / `task` token**：否则「有序 / 无序 / 待办」无法各有其色；设置页自动多出两行，属于本轮范围。
