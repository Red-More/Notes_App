数据主权

你的笔记，应该住在一个
你能带走的文件里。

Notes 不把内容锁进私有格式。每条笔记、每个待办、每份联系人，都是 life.db 虚拟文件系统中的一篇 Markdown；整个库就是一个 SQLite 文件。复制它，就是一次完整备份。

  • 单文件即备份

    把 life.db 复制到新设备，数据完整迁移，不依赖任何云服务。

  • 普通 Markdown

    离开 Notes，任何一个编辑器都能打开这些文件，没有导出锁。

  • 本地全文索引

    SQLite FTS5 建立索引并提供 LIKE 回退，搜索不出这台设备。

常见问题

你可能想先确认的事。

Notes 会把我的数据上传吗？

不会。应用没有账号体系、没有服务器，也没有遥测。AI 功能可选，只有你在对话里主动发送的内容，才会请求到你自己配置的模型接口。

为什么 AI 功能需要自己配置模型？

Notes 不代管模型账号。你可以在设置中添加 OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages 兼容接口，填写 Base URL 与 API Key，密钥只保存在本机。

怎么备份或迁移到新设备？

找到应用数据目录中的 life.db，复制到新设备对应位置即可；单篇文档也可以通过导出功能写到系统目录。

有桌面版安装包吗？

暂未提供预编译桌面安装包。项目支持 Tauri 2 桌面构建，可按 README 在 Windows / macOS / Linux 上自行编译。

为什么安装时提示「未知来源」？

APK 使用项目自签名证书，没有上架应用商店。安装前需要在系统中允许当前应用安装未知应用；SHA-256 校验值可在 Release 页面核对。
